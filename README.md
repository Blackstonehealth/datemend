# Datemend (free preview v0.1.0)

Browser-based tool that writes capture dates, locations and photo captions back onto the files in a Snapchat "My Data" Memories export. Runs on your computer; nothing is uploaded.

**Site:** https://blackstonehealth.github.io/datemend/ · **Tested on generated sample exports only**; not yet verified on a real, current Snapchat export. Not affiliated with Snap Inc. See LICENSE-PREVIEW.txt (draft preview terms).

Please do not post your photos, export, or report in issues.
